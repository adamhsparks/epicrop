# Calculate weighted hourly leaf wetness

Calculate weighted hourly leaf wetness

## Usage

``` r
.calculate_weighted_hr_wet(rh, rhlim)
```

## Arguments

- rh:

  Hourly RH values (%).

- rhlim:

  RH threshold for full wetness (%).

## Value

Weighted wetness values \[0, 1\].
