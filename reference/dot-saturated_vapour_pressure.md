# Calculate saturated vapour pressure

Calculate saturated vapour pressure

## Usage

``` r
.saturated_vapour_pressure(tmp)
```

## Arguments

- tmp:

  Temperature (°C).

## Value

Saturated vapour pressure (kPa).

## References

Alduchov and Eskridge (1996) J. Appl. Meteor. 35:601-609.
