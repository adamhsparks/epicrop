# Utility Function to Check User Inputs for seir()

Sanity checks for user inputs to
[`seir()`](https://adamhsparks.codeberg.page/epicrop/reference/seir.md)
to ensure that they will work.

## Usage

``` r
.check_inputs(seir_passed_args)
```

## Arguments

- seir_passed_args:

  a `list` of values passed to
  [`seir()`](https://adamhsparks.codeberg.page/epicrop/reference/seir.md)

## Value

Nothing, called for its side-effects to check user input values.
