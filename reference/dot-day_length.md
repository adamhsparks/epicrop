# Calculate day length for a given latitude and date

Calculate day length for a given latitude and date

## Usage

``` r
.day_length(lat, doy)
```

## Arguments

- lat:

  Latitude (degrees).

- doy:

  Day of year (1-365).

## Value

Numeric day length in hours.

## References

Forsythe et al. (1995) Ecological Modeling 80:87-95.
