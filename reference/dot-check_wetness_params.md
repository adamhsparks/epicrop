# Check Wetness Parameters

Check Wetness Parameters

## Usage

``` r
.check_wetness_params(simple_wetness, wth, RcW, RcW_arg)
```

## Arguments

- simple_wetness:

  Boolean for simple wetness calculation

- wth:

  Weather data object

- RcW:

  Evaluated RcW parameter (can be NULL)

- RcW_arg:

  Original RcW argument (to check if user provided it)

## Value

Nothing, called for side effects
