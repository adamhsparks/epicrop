# Validate All Simulation Inputs

Central validation function for
[`seir()`](https://adamhsparks.codeberg.page/epicrop/reference/seir.md)
parameters

## Usage

``` r
.validate_all_inputs(
  wth,
  emergence,
  onset,
  duration,
  rhlim,
  rainlim,
  H0,
  I0,
  RcOpt,
  Sx,
  a,
  steps_per_day,
  simple_wetness,
  age_driver,
  RcW
)
```
